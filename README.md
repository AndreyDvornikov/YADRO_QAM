# QAM Simulation

Программа моделирует передачу данных с квадратурной модуляцией QAM (QPSK, 16-QAM, 64-QAM) через канал с аддитивным белым гауссовским шумом (AWGN). Считает вероятность битовой ошибки (BER) для разных мощностей шума и строит график.

- **Модулятор** -- превращает биты в комплексные символы созвездия с кодом Грея и нормированной энергией.
- **Канал AWGN** -- добавляет к символам комплексный гауссов шум с заданной дисперсией.
- **Демодулятор** -- по зашумлённому символу ищет ближайшую точку созвездия и восстанавливает биты.
- **Симуляция** -- генерирует случайные биты, прогоняет через модулятор-канал-демодулятор, считает ошибки.
- **График** -- сравнивает экспериментальный BER с теоретической кривой.

Установка Python-зависимостей:
```bash
pip install -r requirements.txt
```
## Сборка
```bash
mkdir build && cd build
cmake ..
cmake --build .
```
Появится исполняемый файл qam_sim.
## Запуск
### Простой способ (bash-скрипт)
```bash
./run_sim.sh
```
Можно передать свои настройки:
```bash
./run_simulation.sh --M 64 --num-bits 2000000 --seed 123 --out results.txt --plot-output plot.png
```

Скрипт принимает следующие аргументы:

    --M порядок модуляции: 4, 16 или 64 (по умолчанию 16)

    --num-bits количество передаваемых бит (по умолчанию 1000000)

    --seed начальное значение генератора бит (по умолчанию 42)

    --out имя файла для результатов симуляции (по умолчанию ber_results.txt)

    --plot-output имя файла для сохранения графика (по умолчанию ber_plot.png)

### Ручной запуск

Сначала симуляция:
```bash
./build/qam_sim --M 16 --num-bits 1000000 --seed 42 --out ber_results.txt
```

Аргументы qam_sim:

    --M порядок модуляции (4, 16, 64)

    --num-bits общее число бит

    --seed зерно для генерации случайных бит

    --out выходной файл с парами variance BER

Потом график:
```bash
python3 plot_ber.py --input ber_results.txt --M 16 --output ber_plot.png
```

Аргументы plot_ber.py:

    --input файл с данными симуляции (по умолчанию ber_results.txt)

    --M порядок модуляции (по умолчанию 16)

    --output файл для сохранения графика (по умолчанию ber_plot.png)

Результаты

После работы программы в файле ber_results.txt будут строки вида:
```text
0.05 0.017146
0.1 0.058862
...
```
Это дисперсия шума и доля ошибочных битов.

Скрипт plot_ber.py рисует график BER от дисперсии в логарифмическом масштабе. Красная кривая -- теория, синие точки -- симуляция. График сохраняется в файл ber_plot.png.
